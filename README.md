## Featured Projects

### RevRAG AI — Banking & Financial Knowledge Assistant
A retrieval-augmented knowledge assistant that indexes PDF/TXT documents, retrieves relevant passages with TF-IDF, and presents source-grounded answers. Optional LLM answer generation can be enabled with an environment variable.
- **Stack:** Python, Streamlit, scikit-learn, PyPDF, optional OpenAI API
- **Code:** [Open project](./revrag-ai) · [Setup and documentation](./revrag-ai/README.md)

### Tekravio — Business Data Analytics Assistant
A CSV analytics app for data profiling, missing-value inspection, descriptive statistics, and supported natural-language aggregation questions with charts.
- **Stack:** Python, pandas, NumPy, Streamlit, Plotly
- **Code:** [Open project](./tekravio) · [Setup and documentation](./tekravio/README.md)

### Forest AI — Document Processing Agent
A document-intake prototype that extracts text from PDF/TXT files, classifies request types, identifies common fields, and exports structured JSON with human-review flags.
- **Stack:** Python, Streamlit, PyPDF, regular expressions, JSON
- **Code:** [Open project](./forest-ai) · [Setup and documentation](./forest-ai/README.md)
